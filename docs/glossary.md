*[SAST]: Static Application Security Testing — статический анализ исходного кода
*[DAST]: Dynamic Application Security Testing — тестирование запущенного приложения
*[IAST]: Interactive Application Security Testing — агентный анализ внутри приложения
*[RASP]: Runtime Application Self-Protection — самозащита приложения в рантайме
*[SCA]: Software Composition Analysis — анализ зависимостей на CVE
*[OSA]: Open Source Analysis — анализ open-source компонентов
*[SBOM]: Software Bill of Materials — структурированный перечень компонентов ПО
*[MAST]: Mobile Application Security Testing — анализ мобильных приложений
*[ASPM]: Application Security Posture Management — консолидация AppSec-инструментов
*[CSPM]: Cloud Security Posture Management — аудит конфигураций облака
*[CWPP]: Cloud Workload Protection Platform — защита рабочих нагрузок
*[CNAPP]: Cloud-Native Application Protection Platform — сквозная облачная безопасность
*[KSPM]: Kubernetes Security Posture Management — аудит Kubernetes
*[SIEM]: Security Information and Event Management — сбор и корреляция событий ИБ
*[SOAR]: Security Orchestration, Automation and Response — оркестрация реагирования
*[WAF]: Web Application Firewall — фильтрация HTTP-трафика на уровне приложения
*[IaC]: Infrastructure as Code — инфраструктура как код (Terraform, K8s YAML)
*[NVD]: National Vulnerability Database — национальная база уязвимостей (NIST)
*[CVE]: Common Vulnerabilities and Exposures — идентификатор уязвимости
*[CWE]: Common Weakness Enumeration — классификация типов уязвимостей
*[CVSS]: Common Vulnerability Scoring System — система оценки критичности уязвимости
*[OWASP]: Open Web Application Security Project — открытое сообщество AppSec
*[CIS]: Center for Internet Security — бенчмарки безопасности конфигураций
*[CI]: Continuous Integration — непрерывная интеграция
*[CD]: Continuous Delivery / Deployment — непрерывная доставка / развёртывание
*[DevSecOps]: Development + Security + Operations — безопасность встроенная в разработку
*[AppSec]: Application Security — безопасность приложений
*[OSS]: Open Source Software — программное обеспечение с открытым исходным кодом
*[API]: Application Programming Interface — программный интерфейс приложения
*[XSS]: Cross-Site Scripting — межсайтовый скриптинг
*[IDOR]: Insecure Direct Object Reference — небезопасная прямая ссылка на объект
*[MFA]: Multi-Factor Authentication — многофакторная аутентификация
*[RBAC]: Role-Based Access Control — управление доступом на основе ролей
*[DRM]: Digital Rights Management — управление цифровыми правами
*[EULA]: End User License Agreement — лицензионное соглашение конечного пользователя
*[GDPR]: General Data Protection Regulation — регламент защиты персональных данных ЕС
*[SOC]: Security Operations Center — центр операций по безопасности
*[MTTR]: Mean Time to Remediate — среднее время устранения уязвимости
*[NSE]: Nmap Scripting Engine — движок скриптов Nmap
*[VDP]: Vulnerability Disclosure Program — программа ответственного раскрытия уязвимостей
