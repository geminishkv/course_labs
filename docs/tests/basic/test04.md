**2.** На сервере установлен `umask 022`. Разработчик создаёт файл командой `touch secret.conf`. Какие права получит файл и является ли это проблемой для конфигурационного файла с паролями?

- A) `600` — только владелец может читать и писать; для конфига с паролями приемлемо
- B) `644` — владелец читает/пишет, группа и остальные только читают; для конфига с паролями это проблема — посторонние могут читать пароли
- C) `755` — владелец имеет полные права; остальные могут читать и выполнять
- D) `600` — `umask 022` применяется только к директориям, для файлов права по умолчанию `644`

**7.** OWASP ZAP Active Scan обнаружил уязвимость `Reflected XSS` в параметре `q` на странице поиска. Какой HTTP-запрос наиболее вероятно использовался при обнаружении, и почему Active Scan опаснее Passive Scan при работе с production?

- A) ZAP отправил `GET /search?q=<script>alert(1)</script>` — Active Scan отправляет реальные атакующие payload'ы, что может изменить данные или сломать функциональность production-окружения
- B) ZAP только перехватил обычный запрос — Passive и Active Scan не отличаются по воздействию
- C) ZAP отправил `POST /search` с телом `<img src=x>` — POST-запросы не влияют на данные
- D) Разница несущественна — ZAP никогда не изменяет состояние сервера
